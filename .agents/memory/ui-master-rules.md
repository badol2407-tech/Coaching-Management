`docs/UI_MASTER_RULES.md` is the single source of truth for practical UI/UX decisions across EduTrack.

**Why:** The project has many specialized UI handbooks; a master authority prevents conflicting rules while preserving those handbooks as implementation and evidence owners.

**How to apply:** Start UI/UX work with the master rules, then follow the linked token, component, accessibility, responsive, state, navigation, form, dashboard, motion, and AI handbooks. AI-assisted design must preserve existing branding, palette, typography, component style, and usability priorities.
