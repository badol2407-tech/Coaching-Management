---
name: Documentation architecture
description: Durable rule for maintaining EduTrack product documentation
---

EduTrack documentation uses a file-wise handbook system. `docs/PRODUCT_CONSTITUTION.md` is reserved for permanent vision, philosophy, ethical, and foundational principles; implementation standards belong in the focused handbooks under `docs/`.

**Why:** Expanding the constitution indefinitely makes foundational principles difficult to govern, review, and evolve independently from interaction, accessibility, component, engineering, and governance standards.

**How to apply:** Add new standards to the most specific existing handbook, cross-reference related handbooks, and update the constitution only when a principle is genuinely permanent rather than implementation-specific.
